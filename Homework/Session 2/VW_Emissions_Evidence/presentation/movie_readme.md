# Video exports

The MP4 files are timed slide movies generated from the final PowerPoint decks:

- `team_section_3_to_4_minutes.mp4` — about 5:05 including the opening/closing pauses.
- `standalone_15_minutes.mp4` — about 14:50 of timed slides.

The movies contain the slide visuals and timing, with no embedded voice track. Use the matching Markdown speaker notes/script as the narration track. The original editable PowerPoint files remain the source for revisions.
